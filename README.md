# Oxypro MSRA Generator – web version

Open the app: **https://markwendelllontocdotcom.github.io/MEP-MST-Generator/**

Produces Oxypro standard Method Statements (Word) with ITP hold points, the Excel ITP, the Risk Assessment, the combined MSRA file and the Method Statement submittal log / transmittal for MEP works. Everything runs in the browser; project data stays on the computer that uses it.

This repository holds only the built app (`index.html`) and its icon files. It is published from the private source repository; do not edit the files here by hand.
